# old-wares — 中古服の相場を調べるツール

ヤフオク（落札相場）とメルカリ（売り切れ）から **実際に売れた価格** を集めて、
中央値・平均・価格帯・価格分布をブラウザで確認できる Web アプリです。

出品中の希望価格は混ぜません。両方とも「成約した金額」だけを見ます。

![構成](docs/screenshot.png)

## クイックスタート

```bash
git clone https://github.com/pandaman001-art/old-wares.git
cd old-wares
./run.sh            # 初回は venv 作成 + 依存インストールまでやります
```

ブラウザで <http://127.0.0.1:8000> を開き、検索語（例: `ノースフェイス ヌプシ 700`）を入れて
「相場を調べる」を押します。

手動で立ち上げる場合:

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn oldwares.api:app --reload
```

## 「相場」の定義

トップに出る大きな金額は **両サイトの中央値を等ウェイトで平均した値** です。

```
相場 = (ヤフオクの中央値 + メルカリの中央値) / 2
```

平均ではなく中央値を使うのは、極端な高値・安値 1 件で数字が動かないようにするためです。
また件数ではなく等ウェイトにしているのは、片方のサイトに件数が偏っても
相場がそちらに引っ張られないようにするためです。件数で加重した値
（＝全件をプールした平均）も「全件の平均」として並べて表示しています。

| 表示 | 中身 |
| --- | --- |
| 相場 | 各サイトの中央値の単純平均（推奨値） |
| 全件の中央値 | 両サイトをプールした中央値 |
| 全件の平均 | 両サイトをプールした平均（件数で加重されたもの） |
| よくある価格帯 | プールした第 1 四分位 〜 第 3 四分位（中央 50%） |

## ノイズの除去

中古服の実売データは、そのまま平均すると簡単に歪みます。統計に入れる前に落としています。

- **キーワード除外**（既定 ON）: まとめ売り / セット売り / ジャンク・訳あり / レプリカ /
  キッズ・ペット用 / 型紙・カタログ等の「商品違い」/ 本体でないもの。
  ただし **検索語自体に含まれる語のルールは自動的に無効** になります。
  「キッズ ダウン」で探したときに「キッズ」で全部落ちる、といった事故を防ぐためです。
  「セットアップ」は「セット売り」と誤判定しません。
- **価格ガード**: 既定で 300 円未満・300 万円超を除外。詳細設定から変更できます。
- **外れ値除去**（既定 ON）: IQR 法（Tukey, k=1.5）。有効データが 8 件未満のときは何もしません。

除外された出品は捨てずに残してあり、UI の「除外分も表示」で理由つきで確認できます。

## 取得元

| キー | 取得元 | 中身 |
| --- | --- | --- |
| `yahoo` | ヤフオク 落札相場検索 | 過去 120 日ぶんの落札価格を HTML から抽出 |
| `mercari` | メルカリ 検索 API | `STATUS_SOLD_OUT`（売り切れ）のみ。DPoP 署名つきで取得 |
| `demo-yahoo` / `demo-mercari` | デモ | 外部アクセスなし。UI と統計の確認用の擬似データ |

片方が落ちてももう片方の結果は返します。失敗した取得元はエラー内容を画面に出します。

### 取得元まわりの注意

- どちらも公開 API ではありません。**個人的な価格調査の範囲で、常識的な頻度で**使ってください。
  各サービスの利用規約に従うのは利用者の責任です。
- 連続アクセスには既定で 1.2 秒のウェイトを入れ、429/5xx は指数バックオフで
  最大 3 回までしか再試行しません。
- 取得結果は既定 30 分ディスクにキャッシュします（`~/.cache/oldwares`）。
  同じ語を何度も叩いても相手サイトには飛びません。
- ヤフオクの HTML 構造が変わった場合に備えて、パーサは
  「`Product__*` クラスを読む経路」と「詳細リンク近傍の金額を拾う総当たり経路」の
  二段構えにしてあります。両方空振りしたときは
  「1 件も抽出できませんでした」というエラーを返します。

## API

| エンドポイント | 用途 |
| --- | --- |
| `GET /api/search?q=...` | 検索結果と統計を JSON で返す |
| `GET /api/export.csv?q=...` | 明細を CSV で返す（Excel 用に BOM つき） |
| `GET /api/sources` | 利用できる取得元の一覧 |
| `POST /api/cache/clear` | キャッシュを消す |

主なクエリパラメータ: `sources`（カンマ区切り）, `limit`, `price_min`, `price_max`,
`exclude`（カンマ区切りの除外語）, `default_excludes`, `remove_outliers`, `fresh`。
OpenAPI ドキュメントは <http://127.0.0.1:8000/docs> にあります。

```bash
curl "http://127.0.0.1:8000/api/search?q=パタゴニア+レトロX&sources=yahoo,mercari" | jq .blend
```

## CLI（取得元のデバッグ用）

```bash
.venv/bin/python -m oldwares.cli "ノースフェイス ヌプシ 700" --sources yahoo,mercari
.venv/bin/python -m oldwares.cli "パタゴニア レトロX" --json --no-cache
```

## 環境変数

| 変数 | 既定 | 説明 |
| --- | --- | --- |
| `OLDWARES_CACHE_DIR` | `~/.cache/oldwares` | キャッシュの場所 |
| `OLDWARES_CACHE_TTL` | `1800` | キャッシュの有効秒数。`0` で無効 |
| `OLDWARES_REQUEST_DELAY` | `1.2` | 連続ページ取得の間隔（秒） |
| `OLDWARES_USER_AGENT` | Chrome 相当 | 送出する User-Agent |

## 開発

```bash
.venv/bin/pip install -r requirements-dev.txt
.venv/bin/python -m pytest          # 58 tests
```

構成:

```
oldwares/
  api.py            FastAPI（UI + JSON/CSV API）
  service.py        取得元を並列に叩いて相場を組み立てる
  stats.py          要約統計 / IQR 外れ値 / ヒストグラム
  normalize.py      検索語の正規化と除外ルール
  cache.py          TTL つきディスクキャッシュ
  http.py           User-Agent・ウェイト・リトライの共通設定
  sources/          yahoo_auction.py / mercari.py / sample.py
  static/index.html 画面（依存なしの単一ファイル）
tests/              58 tests（パーサは保存済み HTML で検証）
```

## 既知の制約

- **実サイトからの取得は未検証です。** 開発環境から `auctions.yahoo.co.jp` と
  `jp.mercari.com` への通信がネットワークポリシーで遮断されていたため、
  ヤフオク／メルカリの取得経路はローカルの HTML・レスポンス固定値に対する
  テストまでしか行えていません。手元で `--sources yahoo,mercari` を一度実行して
  確認してください。抽出できない場合はパーサの選択子の調整が必要です
  （`oldwares/sources/yahoo_auction.py` の `_parse_structured`）。
- メルカリの検索 API は売却日時を返さないため、メルカリ側の「売却日」は空欄です。
- 送料込み / 送料別は出品ごとに異なり、価格には反映していません。
- サイズ・状態・年式での絞り込みは、いまのところ検索語と除外語で行う形です。
